# The Blue Moon Hotel Mystery / «Тайна отеля „Голубая луна“»

Английский детективный квест (visual novel + поиск улик) уровня Pre-Intermediate (A2–B1).
Цель: естественная практика Past Simple / Past Continuous, предлогов, вежливых просьб — через диалоги, выборы реплик и сбор улик.

## Как играть

- Читай диалог и выбирай лучший ответ (по смыслу, вежливости и грамматике).
- Сова Уотсон объясняет ошибку — попробуй ещё раз, игра не «наказывает».
- В сценах поиска двигай лупу и кликай по подозрительным местам.
- Блокнот хранит улики; кнопка с глобусом показывает перевод реплики; кнопка с совой — подсказку.

## Запуск локально

Сайт статический, достаточно открыть `index.html` через любой веб-сервер:

```bash
python -m http.server 8080
# затем: http://localhost:8080/
```

```
english-quest/

├── assets/               — 42 игровых изображения (фоны, персонажи, UI, улики)
│   └── gallery.html      — галерея всех ассетов с QA-статусами
├── 01_scenario.md        — сценарий и дизайн игры
├── 02_images.md          — список изображений с промптами
├── 03_dialog_script.md   — полный диалоговый скрипт (~164 реплики)

├── manifest.json         — параметры генерации всех ассетов
└── tools/                — пайплайн генерации (ComfyUI-скрипты, rembg, апскейл)
```

## Как делались картинки

- Локально: ComfyUI + SDXL base (28 шагов, cfg 7.0), промпты и сиды — в `manifest.json`.
- Консистентность: единый стиль-префикс, фиксированные сиды, палитра #1B2A4A / #D9A441 / #F3E9D2 / #A63A3A, без текста на изображениях.
- Контроль качества: каждый файл проверен вручную; до 3 попыток на ассет, далее код-фолбэк (SVG).
- Постобработка: прозрачность rembg (u2net/isnet + доп. проходы), фоны 1920×1080 (RealESRGAN x4 + Lanczos).
- Итог: 42/45 PNG приняты; `UI_feedback_icons`, `UI_buttons_set`, `OBJ_testimony` рисуются кодом.
